# Study with Gemini

A Chrome extension (Manifest V3) that lets you select text on any page, press **Shift**, and ask Google Gemini to explain, summarize, or compare it.

👉Demo video: https://www.youtube.com/watch?v=MPTQkfwHrtA

## Setup

1. Clone the repo.
2. Copy `src/config.example.js` to `src/config.js` and put your Gemini API key in it. (`config.js` is git-ignored.)
3. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and select the repo folder.

## Usage

Select text on any web page, press **Shift**, and choose an action from the menu. Use the toolbar popup to turn the extension on or off.
